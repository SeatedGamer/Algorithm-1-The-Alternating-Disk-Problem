## Algorithm 1: Alternating Disks

**Compile:** `g++ -std=c++17 -o alternating_disks alternating_disks.cpp`
**Run:** `./alternating_disks`

**Sample:**
```
Input:  n = 4, L D L D L D L D
Output: D D D D L L L L, swaps = 10
```

---

## Algorithm 2: Connecting Pairs

**Compile:** `g++ -std=c++17 -o couples couples.cpp`
**Run:** `./couples`

**Sample:**
```
Input:  [0, 2, 1, 3]  ->  Output: 1
Input:  [3, 2, 0, 1]  ->  Output: 0
```

---

## Assumptions
- Algorithm 1: input starts with light and alternates.
- Algorithm 2: n ≤ 30 and even, IDs are unique.
